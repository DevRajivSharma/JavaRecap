# What is Java?

Java is a high-level, class-based, object-oriented programming language that is designed to have as few implementation dependencies as possible. It is a general-purpose programming language intended to let application developers write once, run anywhere (WORA).

## History

Java was originally developed by James Gosling at Sun Microsystems (which has since been acquired by Oracle Corporation) and released in 1995 as a core component of Sun Microsystems' Java platform.

## Philosophy

The primary goals in creating Java were:

1. **Write Once, Run Anywhere (WORA)** - Code written in Java can run on any device that has the Java Virtual Machine (JVM) installed, without recompilation.

2. **Simplicity** - Java was designed to be simpler to use than C++, removing complex features like operator overloading, multiple inheritance, and manual memory management.

3. **Object-Oriented** - Java was built around the concept of objects, which can contain data and methods.

## Java Virtual Machine (JVM)

The JVM is an abstract computing machine that enables a computer to run a Java program. The JVM is platform-dependent, but the Java code that runs on it is platform-independent. This is what allows Java to achieve its "write once, run anywhere" capability.

## Java Development Kit (JDK)

The JDK is a software development environment used for developing Java applications. It includes:

- Java Runtime Environment (JRE)
- An interpreter/loader (java)
- A compiler (javac)
- An archiver (jar)
- A documentation generator (javadoc)
- Other tools needed for Java development

## Java Runtime Environment (JRE)

The JRE is a package that provides the minimum requirements for executing a Java application. It consists of:

- Java Virtual Machine (JVM)
- Core libraries
- Supporting files

## Java Editions

Java comes in several editions:

1. **Java Standard Edition (Java SE)** - For general-purpose use on desktops, servers, and similar devices.

2. **Java Enterprise Edition (Java EE)** - For enterprise applications, particularly web applications.

3. **Java Micro Edition (Java ME)** - For applications on mobile devices and embedded systems.

4. **JavaFX** - For creating rich internet applications with a modern user interface.
